# JSPForge Debug Lab — Working Browser Project

## Run
Extract the ZIP and double-click `index.html`.

No Tomcat, JSP server, MySQL, Node.js, npm, or internet connection is required.

## Working flow
1. Enter student name.
2. Select a module.
3. Click **Run Debug Check** to identify and highlight the bug.
4. Click **Apply Correct Fix**.
5. Click **Run Debug Check** again to validate the correction.
6. Write a 30+ character lifecycle explanation.
7. Submit the explanation.
8. Click **Download JSP** to download the corrected JSP.
9. Open **Results** to see progress.

Progress is stored only for the current browser session using sessionStorage. **Logout** or **Start New Session** clears the name, progress, completed modules, and reports so the next student starts from the beginning.

## Modules
1. Declaration Scope — `<%! %>` and request-specific mutable state.
2. Forward vs Redirect — `<jsp:forward>` versus `response.sendRedirect()`.
3. Request vs Session — `requestScope` versus `sessionScope`.

This is a JSP debugging learning simulation. It does not execute JSP on a server.
